# Verbindungen

Notizen des Roommate aus dem Lernsystem ALTER
(`06_wissen/frameworks/ALTER_Lebenslanges_Lernen.md`). Einmal im Monat
verbindet `/roommate` ein laufendes Thema mit einem fernen Fach. Jede Notiz
trägt eine Stufe.

| Stufe | Bedeutung |
|---|---|
| Bild | Merkhilfe, keine neue Frage an das Thema |
| Idee | stellt eine Frage an das Thema, die ein Projekt prüfen kann |
| Framework-Kandidat | trägt über einen Fall hinaus, steht zusätzlich in `06_wissen/frameworks/README.md` |

Ein ausgelassener Monat wird nicht nachgeholt. Die Fächer der letzten drei
Notizen sind für die nächste ausgeschlossen.
