# Projekte im Hub

Ein Ordner je Lernprojekt oder Anliegen, angelegt mit `/new-project
<kurzname>` (Kleinbuchstaben, ohne Nummer). Projekte für einen Arbeitgeber,
die eigene Firma oder Kunden gehören nicht hierher, sondern in den
passenden Ast.

| Typ | Ziel | Was dazugehört |
|---|---|---|
| Lernprojekt | Können | `lernlog.md`, Lehrplan über `/advisor`, Nachweis je Block, geübt in der Spur eines Asts |
| Anliegen | Ergebnis im eigenen Leben | Charter, Methodik mit „Last Validated“, KPIs, fertig nach Definition of Done |

Rohdaten unter `<projekt>/data/input/` sind per `.gitignore` nicht im Repo.
Die Projekttabelle steht in der `CLAUDE.md` des Hubs, Abschnitt 4.
