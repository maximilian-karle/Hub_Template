# Case Studies

Jedes abgeschlossene Vorhaben, jedes Gate eines Moduls hinterlässt hier eine
Fallstudie. Sie sind der Beleg für Bewerbungen, Gespräche und das eigene
Profil. Ein Fall je Datei nach `_Vorlage_Case_Study.md`.

Vor jeder Verwendung außerhalb des Hubs gelten die Regeln aus
`00_kern/vertraulichkeit.md`. Stellen, die noch anonymisiert werden müssen,
sind mit `[ANONYMISIEREN: ...]` markiert.

Eine Case Study ohne gemessenes Ergebnis wird nicht als Erfolg dargestellt.
Was noch Projektion ist, steht als Projektion da.
