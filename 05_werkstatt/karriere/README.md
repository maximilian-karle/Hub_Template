# Karriere

Optional. Für Bewerbungen, Profilpflege und Verhandlungen.

| Ordner | Inhalt |
|---|---|
| `Profil/` | Master-Lebenslauf als Daten, Leistungsnachweise, Zeugnisse (nur im privaten Repo) |
| `Bewerbungen/` | ein Ordner je Bewerbung mit Stellenanzeige, Keyword-Abgleich, zugeschnittenem Lebenslauf und Anschreiben |

Belege kommen aus `../case_studies/`. Eine Aussage im Lebenslauf, die keine
Case Study und keinen Nachweis hat, wird als Anspruch markiert, bis sie
belegt ist.
