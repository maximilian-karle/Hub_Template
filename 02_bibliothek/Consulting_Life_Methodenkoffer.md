# Consulting Methodenkoffer, Eintrag in der Bibliothek

Part of the Information Hub (02_bibliothek/), treated exactly like a book:
inspiration and reference material, not a checklist to follow. Frameworks
for actual projects are DEVELOPED from this and the literature below, then
written up in 06_wissen/frameworks/ (status "In trial", then "Proven"). This
file itself is never the final answer.

Source: consulting-life.de (Dr. Christopher Schulz), a user-curated index of
>210 consulting methods, stored locally so it loads with every session.
Live details on any method: fetch https://www.consulting-life.de/methodenkoffer/

## How to use this index
1. When a framework/tool/method is needed, scan the categories below first.
2. Name the specific method(s) that fit, with the category they're in,
   so the user knows where to look up the full description.
3. Do NOT stop there. Always add your own reasoning: how the method
   should be adapted to the actual situation, whether a combination of
   methods fits better, or whether a method outside this list is more
   appropriate. This index is a starting point, not a ceiling.
4. If the situation calls for something quantitative/technical (e.g.
   optimization models, statistical methods) that isn't in this list,
   say so explicitly, this index is consulting-process-oriented, not
   an operations-research library.
